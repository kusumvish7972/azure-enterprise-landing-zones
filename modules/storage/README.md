# 📦 Azure Hardened Storage Module

Enterprise Terraform child module provisioning secured Azure Blob Storage adhering to CIS benchmarks.

## Capabilities
- **Strict Transport Security**: Minimum TLS 1.2 / TLS 1.3 enforced.
- **Private Link**: Azure Storage Private Endpoints eliminate public exposure.
- **Data Protection**: 30-day soft-delete retention and blob versioning enabled by default.
- **Multi-Tier Redundancy**: Configurable for LRS, ZRS, or Geo-Redundant Storage (GRS).
