# 📊 Azure Monitoring & Observability Module

Enterprise Terraform child module provisioning centralized logging, distributed APM tracing, and alert management.

## Capabilities
- **Log Analytics Workspace**: Centralized ingestion hub for infrastructure, audit, and container telemetry.
- **Application Insights**: Deep APM monitoring, end-to-end distributed transaction tracing, and performance profilers.
- **Action Groups**: Standardized incident routing to SRE & Operations email distribution channels.
